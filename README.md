A front-page image summing up the world's news of Friday 20 November 2026:
GTA VI's $2.36bn day-one sales (Sensor Tower estimate) as the hero story, plus
Cyclone Akvan's landfall, the Shenzhen peace declaration, Phillips' historic 118,
the EU summoning Russia's envoy, world reaction to the ICJ Myanmar ruling, and
Trump's Washington press conference.

The image is drawn programmatically — no AI image generator, no network, no
randomness. `main.py` (Python 3.13, Pillow) renders the masthead, ticker, neon
Vice City hero, headline strip with a mini bar chart, and six news cards into a
single 1024×1024 JPEG. Running it twice produces byte-identical output.

## Run

```sh
python3 main.py
```

The entry image is written to `$MAKEFUN_OUTPUT_DIR/entry.png`
(or `/output/entry.png` by default).
